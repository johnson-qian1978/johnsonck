# 1. 问题背景与挑战

## 核心问题

- **新员工大批量入职** - 回迁初期人员快速扩充
- **技能水平偏低** - 业务能力不足，首问解决率低
- **接续辅导少** - 缺乏一对一指导
- **提单率高** - 问题升级到上级部门

## 解决思路

> 以"首问办结"为核心牵引，结合话务场景特点，动态优化流程规范，多措并举提升人员在线解决能力

---

# 2. 三阶段推进策略

## 第一阶段（10-11 月）- 回迁初期

**核心关注**：新员工技能摸底，首问解决率低位运行

**联动举措**：
- 开展新员工技能摸底评估 → 发现问题清单
- 清理场景发现问题 → 建立问题台账
- 建立首问解决率监测机制 → 每日跟踪

---

# 第二阶段（12-2 月）- 专项攻坚

**核心关注**：聚焦账期/话费/合约等痛点，专项攻坚

**联动举措**：
- 聚焦月头月底账期查询痛点 → 专项研究处理流程
- 话费疑问处理规范优化 → 减少升级工单
- 合约续办流程简化 → 提升在线办结率

---

# 第三阶段（3 月至今）- 成效显现

**核心关注**：全面赋权 + 脚本优化，成效显现

**联动举措**：
- 省分全面赋权在线办理 → 合约续办、套餐变更、权益流量包
- 清理解释脚本优化 → 流量争议、话费争议、停机场景
- 员工快速赋能提升 → 首问解决率显著提升

# 3. 三大核心举措

## 举措一：健全绩效体系

| 具体措施 | 预期效果 |

| 推动服务经验快速复制 | 整体能力提升 |

# 4. 制度保障

## 建立两项核心制度
