### 🔥 踩坑记录（重要，避免重犯）
1. **达梦 VARCHAR2(n) 按字节计长**：1 汉字 = 3 字节。`DSSWJG VARCHAR2(11)` 只能存 ~3 汉字。
   我填「江汉区税务局」直接报"列长度超出定义"，改成税务代码「420103」才行。
2. **达梦自增列不能手动赋值**：SYS_MENU.MENU_ID / SYS_DICT_TYPE.DICT_ID / SYS_DICT_DATA.DICT_CODE
   都是 IDENTITY。INSERT 不指定这些列，引用父 ID 用子查询 `(SELECT MENU_ID FROM ... WHERE ...)`。
3. **disql 执行中文 SQL 要 GBK 编码**：disql 默认按 GBK 读脚本。用 UTF-8 文件会中文乱码 + 引号错位。
   用 Python `io.open(path,'w',encoding='gbk')` 生成脚本，再 `DIsql.exe ... @脚本.sql`。
4. **DateUtils.getTime() vs dateTimeNow()**：本项目 `getTime()` = `yyyy-MM-dd HH:mm:ss`（正确），
   `dateTimeNow()` = 紧凑 `yyyyMMddHHmmss`（错）。第一次用错导致录录时间显示为 20260910160510。
5. **Redis 取验证码测试登录**：验证码存在 Redis key `captcha_codes:<uuid>`，值是 JSON 包裹的字符串
   （如 `"8"`），需 JSON.parse 还原。用 Node 原生 net 模块发 RESP 协议即可读，无需 redis 客户端。
