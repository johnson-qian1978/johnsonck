### 🔥 踩坑 13：GH_DM_JFFPBL 主键是 NUMBER 且非自增
其他表 LSH 都是 VARCHAR2（UUID），只有这张是 `LSH NUMBER NOT NULL` 且**没有 IDENTITY**（实测不填报 -6609 非空约束）。
生成器默认 `IdUtils.simpleUUID()` 会编译不过。
**解决**：给 gen_module.py 加 `pkJava` 配置（默认 String，可设 "Long"）：
- domain 主键字段 Long；mapper/service/controller 签名用 Long / Long[]
- XML 多生成 `selectMaxLsh`（`select NVL(MAX(LSH),0)`）
- ServiceImpl.insert 里 `lsh == null` 时取 max+1；Controller 不再塞 UUID
实测连插 3 条，主键 = 1/2/3 ✅
