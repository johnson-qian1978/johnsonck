## ⚠️ 坑（重要教训）
1. **工具显示层的 `***` 脱敏**：`var X = {` 显示为 `var X = ***`。若从显示内容复制 `***` 回写，文件会真的写入 `***` 导致 JS 语法错误！→ 写代码时 `{` 必须自己敲，写完必须 `node --check` 校验
2. PowerShell 5.1 不支持 `&&`，用 `;`
3. agent-browser 的 find text click 有时点不中按钮，用 eval 直接 click() 更可靠
4. exec 内联 python 写多行中文+特殊字符字符串易踩转义坑 → 改用 write 工具写文件
